## はじめに

AWS Builder Cardsは、AWSのサービスを組み合わせてアーキテクチャを考えるカードゲームです。
今回、初めてAWS Community Buildersのイベントに参加したので、参加するまでの過程と感想を記事にしてみました。(オフラインイベントに参加するのも初めてです)

AWSについて勉強しているエンジニアや、コミュニティに参加したいけれど自分のように勇気がなくて一歩踏み出せない方にとって、少しでも力になれればいいなと思います！

### 参加したイベント詳細

[【東京支部x千葉支部コラボ】AWS BuilderCardsで遊ぼう！](https://jawsug.connpass.com/event/405305/)

### 参加申し込みするまでの経緯

業務でAWSを使用する機会が増えたこともあり、AWSの資格勉強を通してAWSへの興味・関心が高まってきていました。
また、AWS関連で技術記事やXの投稿を探すと、`JAWS-UG`というコミュニティによる情報発信が多く、記事を追いかけていくうちにオフラインイベントへの興味が湧いてきました。

そんな中、AWS Builder Cardsというものの存在を知り、もともと遊戯王やデュエルマスターズにはまっていた身としては心惹かれるものがあり、勇気を出して一歩を踏み出したという流れになります。

<details>
 <summary>JAWS-UGとは？</summary>

:::note info
JAWS-UGとは、AWS (Amazon Web Services) が提供するクラウドコンピューティングを利用する人々の集まり（コミュニティ）です。
日本全国に様々な支部を持ち、支部ごとに（時には連携しながら）様々なイベントを通してAWS利用に関する知見を発信したり、共有したりしています。
:::

</details>

<details>
<summary>AWS Community Buildersについて</summary>

:::note info
AWS Community Builderとは、AWSに関する知識の共有や技術コミュニティへの貢献を認め、AWSが認定するプログラムのことです。

`JAWS-UG`はこうしたBuilderたちによって運営されており、地域や業務領域などによっていくつか支部があったりします。`JAWS-UG`主催のイベントはオンライン・オフラインを問わず積極的に開催されており、過去には某テレビ番組のように24時間ぶっ通しでイベントが開催されるなど、その熱量はものすごいです！

## AWS Builder Cardsについて

### 遊び方

ここでは簡単に概要を説明しますが、詳細は[公式ページ](https://aws.amazon.com/jp/builders-flash/202405/japanese-builder-cards/)を参照ください。

2〜4人でゲームを開始し、1人ずつターンが回ってきます。
自分のターンになったら山札から数枚取って手札に加え、その手札の中でAWSサービスを使った（場合によってはオンプレリソースも含めて）アーキテクチャを作り上げます。

より良いアーキテクチャであればあるほどポイントが高くなり、得たポイントを使って追加でカード（AWSのサービス）を取得したり、`Well-Architected Point`を獲得したりします。
そして、最終的に`Well-Architected Point`を一番稼いだプレイヤーの勝ち、というゲームです。

### 拡張パックという楽しみ方

AWS Builder Cardsには通常版の他にセキュリティパックやGaloreといった拡張パックがあり、慣れてきたらこれらの拡張パックを使ってより広範囲で技術的な内容にすることもできます。

イベントでは上記の2つもプレイさせていただきましたが、セキュリティパックはサイバー攻撃を防ぐための拡張性・堅牢性・監視体制などにも気を配らなければならないなど、アーキテクチャの構築により深みが増す内容でした！（AIに特化した、Generative AI add-onという拡張パックもあるそうです。）

## 実際にプレイしてみた

4人1組で10組以上のテーブルが組まれていましたが、参加者の中にはプレイ経験者もいたため、特に詰まることもなくスムーズにプレイできました！
テーブルのメンバーがほぼ初心者でも、サポート可能な運営の方が何人もいるため、ゲームのルールや進行についてその都度質問しながら進められたと思います。（テーブルに付きっきり、とまではいかないですが、すぐ近くに一人は常にいる感じでした）

最初は自分も含めて恐る恐るルールを確認しながらのプレイでしたが、ゲームの流れをつかむと意外と順番が早く回ってきて、AWSサービスのアーキテクチャに関して議論する時間が増えました。

「議論」といっても特に難しい話をするわけではなく、「DynamoDBとRDSをどう使い分けよっかな……」「ログイン情報とかのキャッシュと、永続化して保持したいユーザーデータで分ければいいんじゃない？」のような相談やアドバイスの場でもあり、個人戦というよりもむしろチーム戦のような感覚になりました。

### AWS Builder Cardsのここが面白い！

AWS Builder Cardsは勉強半分、ゲーム半分でプレイでき、ジュニアエンジニアからシニアエンジニアまで経験や知識がバラバラでもプレイできる点が魅力です。
むしろ、経験や技術領域がバラバラであればあるほど面白い、とも言えると思います！

特に面白いと感じた点は、**構築したアーキテクチャを自分で説明しなければならない**という点です。

もちろん説明できなくてもカードに説明が書いてあるのでゲームはできますが、「このサービスとこのサービスは直接連携できなくない？」というマサカリが飛んできたり、逆に「このサービスがあるならこっちと組み合わせたほうがコスパよさそう！保守性も高まるし実務っぽい」のようなアドバイスをもらえることもあります。

そして、今まで触ってきたAWSサービスが他のサービスとどんな関わりを持って広がっていくのかを、自分で考えられるのは非常にワクワクします！
実際にハンズオンで触れるには学習コストがかかりますが、AWS Builder Cardsであれば毎ターン、好きなアーキテクチャを作っては壊すことを繰り返せるので、はるかにコスパがいいです！笑

## プレイを通じて気づいたこと

1枚のカードにAWSのサービスが1つ載っているので、単純に「このサービスなんだっけ？」という学びもありつつ、それぞれをどう組み合わせるか、組み合わせた結果どのような業務やシステムができあがるのか、ということについても理解を深められます。

その点で、AWSのサービスをまったく知らなくてもある程度成り立つのですが、知ったうえでプレイするとより面白いです。

## 勉強会に参加してよかったこと

お土産として、日本語版のAWS Builder Cardsをいただけたのはとてもうれしかったです！まさかもらえると思っていなかったので、1人1つの配布は衝撃でした。

この記事を書いたのも、感謝の気持ちとして少しでも布教に携われたらと思ったからです。
まだまだCommunity Builderの方々には及びませんが、少しでも感謝の輪が広がればうれしいです。

## これから参加する人へ

### どんな人におすすめしたいか？

とりあえず「AWSに興味がある人」や「AWSについてより理解を深めたい人」に幅広くおすすめです！
イベントにはAWSを業務でほとんど触らない人も参加していましたが、楽しくプレイされていたので理解度で気後れする必要は全くないです。
強いて言うなら、アーキテクチャの話をしすぎると1ゲームあたりの時間が長くなってしまうので、「勉強半分、遊び半分」の意識が結構大事かもしれません。

### 参加前に知っておくとよさそうなこと

AWSサービスについてあまり知らなくても十分楽しめますが、ざっくりとしたインフラ知識はないと楽しくないと思います。
その場合、後で振り返れるようなメモを取っておくことをおすすめします！
（自分は`CodeCatalyst`というサービスと、`クラウドリフト`という言葉が分からずついていけなかったため、帰りの電車ですぐに調べました）

また、オフラインイベントでは名刺やXのアカウントで自己紹介をするケースも多かったので、できれば用意しておくとよいです。

## まとめ

### AWS Builder Cardsをプレイした感想

とにかく楽しかったです！自分のように「なんとなく興味があるな」くらいの温度感が、「勉強半分、遊び半分」の雰囲気と見事にマッチしていて、充実した時間を過ごせたような気がします。

### 今後やってみたいこと、参加してみたい活動

やはり複数人でプレイするゲームなので、色々な方ともっとプレイをしてみたいと思いました。
職種・言語が違っても遊べますし、むしろその方が様々なアーキテクチャを知れるので色々なコミュニティでプレイしてみたいです。

また、参加者の方々が口をそろえて言っていたのが、「AWS Builder Cardsを社内で広めたいけれど、なかなか機会がない」ということでした。

時間を設けたり、人数を集めたり、業務内でプレイしたりといったことを考えると社内では難しいことも多く、参加者の方々がこうした機会を大切にされている印象でした。
その点、自分はSESとして社内で広められそうな環境にいる気がするので、何かしらの方法で布教に携わっていきたいと思います！
